## Description

This project provides a comprehensive bioinformatics analysis of Epimerase Deficiency Galactosemia (GALE Deficiency / Type III Galactosemia), a rare inherited metabolic disorder caused by mutations in the *GALE* gene encoding UDP-galactose 4-epimerase. We analyze its genomic variants, structural impact on GALE enzyme function, metabolic pathway alterations, and disease phenotypes using multi-omics data and computational tools.
